# cfsearch

**Поиск реального IP-адреса сервера за Cloudflare (или любым CDN) путём сканирования IP-диапазонов.**

## Описание
`cfsearch` — быстрое и лёгкое средство на Go для поиска реального IP-адреса сайта, скрытого за CDN (например, Cloudflare). Инструмент отправляет HTTP/HTTPS-запросы на указанные IP-адреса с подставленным заголовком `Host` и проверяет, содержится ли домен в теле ответа (при статусах 200,301,308).

## Возможности
- Сканирование IP из CIDR-диапазонов или из файла со списком адресов.
- Настройка количества одновременных проверок (`-workers`) и таймаута запроса (`-timeout`).
- Поддержка HTTP и HTTPS (проверка TLS отключена для скорости).
- Индикатор прогресса (`-progress`) для длительных сканирований.
- Найденные IP дописываются в файл (по умолчанию `cfsearch.txt`).
